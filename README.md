## Data & Modeling
* **Data Source:** starbucks.csv, directory.csv
* **Data Preparation:** Cleaning, transformations, and relationships handled in Power Query / Power BI data model.
* **Key DAX Measures:**
  * `[Total Beverages]`
  * `[Average sugar]`
  * `[Average Calories]`

## How to Use
1. Clone or download this repository.
2. Open `starbucks_analysis.pbix` in **Power BI Desktop**.
3. Use the interactive filters, slicers, and cross-visual selections to explore trends by time, category, or segment.

## Notes
* Sensitive or proprietary data has been excluded or anonymized.
* Built with Microsoft Power BI.
